## Complete 18-Volume Architecture & Engineering Suite

This directory contains the authoritative blueprint files governing the design, engineering, testing, and deployment of the AIITS enterprise platform:

1. [01. Project Charter & Academic Vision](./01_PROJECT_CHARTER_AND_VISION.md)
   - Academic metadata, problem statement, core objectives, scope boundaries, and project KPIs.
2. [02. System Requirements Specification (SRS)](./02_SYSTEM_REQUIREMENTS_SPECIFICATION.md)
   - IEEE 830-aligned functional requirements (FR-AUTH through FR-COMM) and non-functional requirements.
3. [03. Three-Tier System Architecture](./03_THREE_TIER_SYSTEM_ARCHITECTURE.md)
   - Presentation, Application, and Data Tier architectural decomposition and data flow diagrams.
4. [04. Database Schema & Data Dictionary](./04_DATABASE_SCHEMA_AND_DATA_DICTIONARY.md)
   - ER diagram, table structures, field definitions, foreign key constraints, and relational mappings.
5. [05. Role-Based Access Control (RBAC) Framework](./05_ROLE_BASED_ACCESS_CONTROL_RBAC.md)
   - Governance matrix across Admin, Store Manager, Permanent Faculty, and Visiting Faculty roles.
6. [06. Asset Lifecycle & Inventory Management](./06_ASSET_LIFECYCLE_AND_INVENTORY_MANAGEMENT.md)
   - Asset states, condition grades (New, Good, Fair, Damaged), category definitions, and field audits.
7. [07. Issuance & Return Workflows](./07_ISSUANCE_AND_RETURN_WORKFLOWS.md)
   - Step-by-step check-out and check-in triage handback procedures with dual-party timestamping.
8. [08. Smart Clearance Prediction Engine](./08_SMART_CLEARANCE_PREDICTION_ENGINE.md)
   - The flagship intelligent feature: 15-day pre-expiry contract countdown and AI notice generation.
9. [09. No Demand Certificate (NDC) Workflow](./09_NDC_NO_DEMAND_CERTIFICATE_WORKFLOW.md)
   - Digital exit clearance pipeline, liability balance reconciliation, approval hierarchy, and certificates.
10. [10. QR & Barcode Operational Framework](./10_QR_AND_BARCODE_OPERATIONAL_FRAMEWORK.md)
    - Cryptographic payload structure, batch generation, printable sticker layouts, and asset binding.
11. [11. Mobile Application Specification (Faculty & Staff)](./11_MOBILE_APP_SPECIFICATION_FACULTY.md)
    - Cross-platform mobile PWA / React Native architecture for faculty self-service and mobile scanning.
12. [12. Communication & Chat System Specification](./12_COMMUNICATION_AND_CHAT_SYSTEM_SPEC.md)
    - Role-bounded real-time internal messaging channels and contact directory specifications.
13. [13. Notifications & Alerting Pipeline](./13_NOTIFICATIONS_AND_ALERTING_PIPELINE.md)
    - Event-driven notifications, state triggers, unread counters, and dropdown interaction design.
14. [14. Forensic Audit Logging & Security](./14_FORENSIC_AUDIT_LOGGING_AND_SECURITY.md)
    - Immutable forensic audit ledger, tamper-evident logs, SQL injection prevention, and API security.
15. [15. API Specification & Contracts](./15_API_SPECIFICATION_AND_CONTRACTS.md)
    - REST endpoint contracts with HTTP methods, request bodies, query parameters, and response schemas.
16. [16. Testing & Quality Assurance Plan](./16_TESTING_AND_QUALITY_ASSURANCE_PLAN.md)
    - Quality objectives, acceptance criteria, comprehensive test cases matrix, and regression checklist.
17. [17. Deployment & DevOps Guide](./17_DEPLOYMENT_AND_DEVOPS_GUIDE.md)
    - Container setup, environment configuration, SQLite-to-PostgreSQL migration, and backup protocols.
18. [18. Implementation Roadmap & Milestones](./18_IMPLEMENTATION_ROADMAP_AND_MILESTONES.md)
    - Phase-by-phase project development timeline from SDP-1 proposal to campus-wide production rollout.
